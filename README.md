# WriteGo Website — GitHub Pages Ready

A React + Vite + Tailwind CSS website for WriteGo.

## Included
- Complete `src/` application code
- All website pages and reusable components
- `package.json` and `package-lock.json`
- `public/` assets
- Vite configuration
- GitHub Pages deployment workflow in `.github/workflows/deploy.yml`

## GitHub Pages
Upload the contents of this folder to the repository root on the `main` branch. The included GitHub Actions workflow builds the site and deploys the `dist` folder to GitHub Pages.
