# WriteGo Website — Version 1.0

A React + Vite + Tailwind CSS website for a professional writing agency.

## Run locally

Install Node.js first, then in this folder run:

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build

```bash
npm run build
```

The production files will be created in `dist/`.

## Important before launch

- Replace placeholder statistics with verified numbers.
- Replace placeholder testimonials with real client testimonials and permission where appropriate.
- Connect the contact form to a real form/email service.
- Replace the starter Privacy Policy and Terms with your final legal text.
- Add your final logo and portfolio images if required.
